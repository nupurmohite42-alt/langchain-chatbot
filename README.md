# LangChain Chatbot

A simple AI chatbot built using:

- LangChain
- NVIDIA NIM API
- Streamlit

## Features

- Chat memory
- Streaming responses
- Prompt Template
- LCEL (LangChain Expression Language)

## Run locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
streamlit run app.py
```
